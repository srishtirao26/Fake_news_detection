# ❤️ Heart Disease Prediction using Machine Learning

This project predicts the likelihood of heart disease using machine learning techniques. It includes data preprocessing, exploratory analysis, model training, and performance evaluation to classify patients as having heart disease or not based on their medical attributes.

## 📌 Features
- Data preprocessing and cleaning
- Feature and target separation
- Train-test data splitting
- Machine learning model training
- Model evaluation using classification metrics
- Prediction on new patient data

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Scikit-learn
- Matplotlib (if used)

## 📂 Project Structure
```
Heart-Disease-Prediction/

```

## 🚀 How to Run
1. Clone the repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run all cells in sequence.
5. Use the trained model to make predictions on new data.

## 📊 Dataset
The dataset contains medical information such as age, sex, chest pain type, resting blood pressure, cholesterol, maximum heart rate, and other clinical features used to predict the presence of heart disease.

## 🎯 Result
The trained machine learning model classifies whether a patient is likely to have heart disease, providing an effective tool for early diagnosis and decision support.
